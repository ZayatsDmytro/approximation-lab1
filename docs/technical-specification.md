# Технічне завдання: «Апроксимація функцій методами інтерполяції та МНК»

Варіант 14 · Заяць Д. І., ІПЗ-1 · 24.10.2026

## 1. Мета та вхідні дані

Розробити односторінковий вебзастосунок, що будує інтерполяційні поліноми Лагранжа й Ньютона та апроксимацію методом найменших квадратів (МНК) для трьох наборів точок варіанту 14 і порівнює їх на графіках.

Стек: HTML5, CSS3, чистий JavaScript (ES2015+ без модулів), HTML5 Canvas 2D. Сторонні бібліотеки для графіків і математики заборонені.

| --- | --- | --- | --- |
| «5 точок» | 5 | Близько до y = x³ із шумом | (-2, -8.2), (-1, -1.1), (0, 0.2), (1, 0.9), (2, 8.1) |

Назва перемикача «10» зберігається як у методичці, але в підписах інтерфейсу показується фактична кількість точок (n = 8).

## 2. Функціональні вимоги

### 2.1. Дані

- **ФВ-1. Вибір набору.** Перемикач «5 / 10 / 20» завантажує відповідний вбудований набір і перераховує всі результати.
- **ФВ-2. Ручний ввід.** Таблиця точок з полями x та y, кнопки «Додати точку», «Видалити», «Скинути до варіанту». Також ввід текстом: пари `x y` або `x;y` по рядку.
- **ФВ-3. Валідація.** Мінімум 2 точки, значення — скінченні числа, x не повторюються. Помилки показуються біля поля, розрахунок не запускається.

### 2.2. Інтерполяція

- **ФВ-4. Поліном Лагранжа** степеня n − 1 за формулою з базисними поліномами lᵢ(x).
- **ФВ-5. Поліном Ньютона** через поділені різниці; обчислення за схемою Горнера.
- **ФВ-6. Таблиця поділених різниць** (трикутна, від f[xᵢ] до f[x₀,…,xₙ₋₁]); коефіцієнти полінома Ньютона виділені.
- **ФВ-7. Перевірка.** Значення Лагранжа і Ньютона збігаються у вузлах і в контрольних точках; показується максимальна розбіжність.

L(x) = Σ yᵢ · Π_{j≠i} (x − xⱼ)/(xᵢ − xⱼ)

N(x) = f[x₀] + Σ f[x₀,…,xₖ] · Π_{j<k} (x − xⱼ)

### 2.3. МНК

- **ФВ-8. Степінь полінома m = 1…4**; m < n, інакше видається попередження.
- **ФВ-9. Розв'язок через QR-розклад** дизайн-матриці A (n × (m+1)) методом Хаусхолдера; далі R·a = Qᵀ·y зворотною підстановкою. Нормальні рівняння AᵀA не використовуються.
- **ФВ-10. Залишки** rᵢ = yᵢ − P(xᵢ) у таблиці; підсумки: SSE, RMSE = √(SSE/n), max |rᵢ|, R².
- **ФВ-11. Вивід коефіцієнтів** полінома МНК у вигляді формули P(x) = a₀ + a₁x + … + aₘxᵐ.

### 2.4. Графіки

- **ФВ-12. Шість полотен Canvas:** 3 для Лагранжа (набори 5 / 10 / 20) і 3 для МНК; на графіках МНК — відрізки залишків.
- **ФВ-13. Автомасштабування осей** за діапазоном точок і кривих з відступом 10 %, «гарні» кроки сітки (1, 2, 5 × 10ᵏ). Для Лагранжа на 20 точках (ефект Рунге) хвости екстраполяції обрізаються з позначкою.
- **ФВ-14. Легенда** на кожному графіку: точки даних, крива (назва методу і степінь), залишки.
- **ФВ-15. Підказки при наведенні:** координати точки, значення моделі, похибка в точці.
- **ФВ-16. Анімації:** покрокове додавання вузлів Лагранжа, «виростання» полінома МНК, поступова поява залишків.
- **ФВ-17. Перемикач режиму «Інтерполяція / МНК / Усі».**

## 4. Інтерфейс користувача

1. **Шапка:** назва роботи, варіант 14.
2. **Панель керування:** перемикач наборів «5 / 10 / 20»; перемикач режиму «Інтерполяція / МНК / Усі»; вибір степеня МНК m = 1…4.
3. **Панель даних:** редагована таблиця точок, текстове поле для вставки пар x y, кнопки «Застосувати», «Скинути до варіанту».
4. **Результати:** вкладки «Набір» і «Порівняння» (6 графіків), таблиця поділених різниць, таблиця залишків МНК.

## 5. Обмеження та критерії приймання

### Обмеження

- Без ES-модулів і без `fetch` локальних файлів — дані вбудовані в js/data.js.
- Без бібліотек (Chart.js, D3, math.js тощо); лише Canvas 2D API.
- Степінь МНК m ≤ 4 і m ≤ n − 1.
- Інтерполяція на 20 рівновіддалених точках дає поліном 19-го степеня з коливаннями на краях (ефект Рунге) — очікувана поведінка.

### Критерії приймання

- [x] index.html відкривається подвійним кліком і працює без сервера та інтернету.
- [x] Усі 6 графіків будуються для наборів 5 / 8 / 20 точок.
- [x] Криві Лагранжа і Ньютона проходять через усі вузли; розбіжність ≤ 1e−9.
- [x] Таблиця поділених різниць відповідає ручному розрахунку для набору «5 точок».
- [x] МНК при m = 3 на наборах 5 і 8 точок дає коефіцієнт при x³ ≈ 1, R² > 0.99.
- [x] Залишки й SSE змінюються при зміні m.
- [x] Перемикачі, легенда, підказки, анімації та автомасштабування працюють.
- [x] Некоректний ручний ввід показує помилку і не ламає сторінку.
